# Документация проекта (OPD_lab4)

## О проекте
* **База:** бесплатный шаблон **FirstPersonHorrorKit** (хоррор от первого лица).
* **Движок:** Unreal Engine **5.8** (только Blueprints, без C++).
* **Хранилище:** все ассеты лежат в Git LFS.

## Как запустить
1. Склонировать репозиторий, выполнить `git lfs pull` и `git submodule update --init`.
2. Открыть `OPD_lab4.uproject` в UE 5.8 (первый запуск долгий из-за компиляции шейдеров).
3. **Карты** (папка `Content/FirstPersonHorrorKit/Levels/`):
   * `MainLevel` — главное меню.
   * `FirstPersonMap` — игровой уровень (можно запускать сразу отсюда).

> **Примечание для Git:** Игровая карта использует режим *One File Per Actor* (акторы сохранены отдельно в `__ExternalActors__`), что позволяет редактировать уровень в команде без конфликтов слияния.

## Управление
Настроено через систему **Enhanced Input** (ассет `Input/IMC_Default`):

| Клавиша | Действие | Input Action |
|---|---|---|
| **W, A, S, D** | Движение | `IA_Move` |
| **Мышь** | Обзор | `IA_Look` |
| **Пробел** | Прыжок | `IA_Jump` |
| **Left Shift** | Бег (время ограничено) | `IA_Sprint` |
| **C** | Присед | `IA_Crouch` |
| **F** | Фонарик (вкл/выкл) | `IA_Flashlight` |
| **ПКМ** | Прицеливание (зум) | `IA_Aim` |
| **Alt+Enter / F11** | Полноэкранный режим | — |

## Структура проекта (`Content/FirstPersonHorrorKit`)
* **`Blueprints/`** — вся логика: игрок (`Player`), враг и его ИИ (`Enemy`), тряска камеры (`Camera`).
* **`Characters/`** — модели рук игрока, манекены и анимационные блюпринты (`ABP_FirstPerson`, `ABP_Enemy`).
* **`Widget/`** — интерфейс (меню, HUD, прицел, эффект нагрудной камеры).
* **`Input/`** — настройки управления.
* **`Audio/`** и **`Misc/`** — звуки, физматериалы поверхностей и пост-процессы.
* **`Demo/`** — сторонние ассеты (анимации зомби, фонарик, блочная геометрия уровня, частицы).

## Основные механики

### 1. Игрок (`BP_FirstPersonCharacter`)
Управляется через `BP_FirstPersonPlayerController`, игровой режим — `BP_FirstPersonGameMode`.
* **Передвижение:** ходьба, спринт с выносливостью и сменой угла обзора (FOV), плавный присед, прыжки.
* **Фонарик:** прикреплён к рукам, включается/выключается по кнопке.
* **Звук шагов и шум:** луч (Trace) под ногами определяет тип поверхности (`Wood` или `Concrete` в настройках движка) и проигрывает нужный звук. Шаги создают шум (`ReportNoiseEvent`), который слышат враги; громкость зависит от скорости движения.
* **Камера:** эффекты покачивания при ходьбе (Headbob), наклоны в стороны при стрейфе и фильтр «бодикамеры».
* **Наведение на врага:** сфера-трассировка перед игроком ищет врагов. При наведении меняется прицел, а сам враг подсвечивается контуром (`M_EnemyOutline`).
* **Здоровье:** при получении урона от врага на экране появляется эффект крови.

### 2. Враг и ИИ (`BP_Enemy`)
Поведение задано через контроллер `BP_AI_Controller`, дерево поведения `BT_AI_Enemy` и память `BBD_AI_Enemy`.

**Логика работы ИИ:**
1. **Патрулирование (`BTTask_Look_Around`):** пока враг не видит и не слышит игрока, он выбирает случайные точки на NavMesh и ходит между ними.
2. **Обнаружение:** через систему восприятия (AI Perception) враг реагирует на зрение и звук шагов игрока. При обнаружении включается флаг `CanChasePlayer?`.
3. **Погоня и атака (`BTTask_Chase_Player`):** враг бежит к игроку. Подойдя вплотную, проигрывает анимацию удара и наносит урон через интерфейс `BPI_EnemyAttack`.

На уровне враги появляются в точках `BP_EnemySpawn`. логика спавна описана в блюпринте уровня

### 3. Интерфейс (`Widget/`)
* **`BP_MainMenu`** — главное меню с кнопками старта игры и выхода.
* **`BP_HUD`** — игровой интерфейс: полоска громкости шагов игрока, иконка фонарика, индикаторы обнаружения врагом и кровавый экран при уроне.
* **`BP_Crosshair`** — динамический прицел (реагирует на врагов).
* **`BP_Bodycam`** — рамка и искажения нагрудной камеры.
